 What I Learned
1️⃣ What is HTTP/HTTPS?
HTTP = HyperText Transfer Protocol
How browsers and servers communicate
HTTPS = Encrypted version using SSL/TLS
2️⃣ HTTP Request Structure
GET /index.html HTTP/1.1
Host: www.example.com
User-Agent: Mozilla/5.0
3️⃣ HTTP Methods
Method	Purpose
GET	Read/Fetch data
POST	Create/Send data
PUT	Update data
DELETE	Remove data
4️⃣ Status Codes
Code	Meaning
200	OK — Success
201	Created
301	Moved Permanently
404	Not Found
500	Internal Server Error
5️⃣ Headers
Carry extra info with requests/responses
Example: Content-Type, Authorization, Cookie
6️⃣ Cookies
Small data stored in browser
Helps server remember users
Used for sessions & authentication

 Practical Application

Applied this knowledge in a REST API Challenge:

Made GET request to fetch user list
Made POST request to update user data
Made DELETE request to remove a user

Theory directly connected to real practice! 

 Key Takeaway

HTTP is the foundation of the web. Understanding it is essential for both cybersecurity and web development.
